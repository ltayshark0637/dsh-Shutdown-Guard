# 本仓库的六个身份

一个调度台 + 五个执行身份。调度台不写产品代码，只拆活、派活、验收；执行身份各自拥有文件，**只改自己名下的路径**。

| # | 身份 | 文件 | 拥有（写权限） |
| --- | --- | --- | --- |
| 00 | 调度台（lead） | `00-dispatch.md` | `AGENTS.md`、`agents/**`、`_ops/**`、`_archive/**` |
| 10 | 宿主内核 | `10-host-core.md` | `lib/index.mjs` |
| 20 | 侧边栏界面 | `20-sidebar-ui.md` | `lib/client.js`、`lib/i18n.mjs` |
| 30 | 测试与验证 | `30-test-verify.md` | `test/**` |
| 40 | 文档与素材 | `40-docs-assets.md` | `README*.md`、`docs/**`、`scripts/gen-*.cjs`、`scripts/screenshot.ps1`、`screenshots.json`、`preview/**`（只读引用） |
| 50 | 发布与运维 | `50-release-ops.md` | `package.json`、`CHANGELOG.md`、`cordis.patch.yml`、`.github/**`、`scripts/push*.ps1`、`scripts/npm-publish.ps1`、git 提交与 tag、DSH 加载链 |

## 为什么必须跨 Agent 通讯

六个身份**互相看不见对方的上下文**。你改了什么、跑过什么、为什么这么改，只存在于你的对话里；别人只能看到磁盘上的文件。所以：

1. **磁盘是唯一共享状态，消息是唯一的解释渠道。** 文件变了但没人说，等于事故：UI 改坏了状态字段，测试会在半小时后以一个看不懂的断言失败来"通知"你。
2. **契约是五个人共用的一条线。** 状态字段、事件名、配置键、文案 key —— 任一变化都会同时打到宿主、界面、测试、文档四个身份。**谁改契约，谁负责广播**（见下）。
3. **越界修改比不修改更糟。** 你顺手在别人的文件里改一行，会让 owner 下次基于错误认知做决策，且没有人为那行代码负责。
4. **交接必须自包含。** 收消息的人看不到你之前的对话，所以消息里不能出现"上面那个文件""刚才那个 bug"。

## 通讯协议（所有身份共同遵守）

**每次给另一个身份发消息，必须包含这六项，缺一项视为无效消息：**

```
【任务】一句话说清要对方做什么
【依据】涉及的文件完整路径 + 关键行号/函数名
【我已做】我改了什么、跑过什么命令、结果
【请对方做】明确的动作，不用"看看""优化一下"
【验收】怎么判定你做完了（命令或可观察结果）
【时限】需要多久内回；超时我按未读处理
```

**广播规则（契约变更）**

| 变了什么 | 必须通知谁 |
| --- | --- |
| `lib/index.mjs` 的 state 字段 / 事件名 / 配置键 | 20、30、40 全部 |
| 卡片上可见的文案 key | 40（三语 README 与 demo 都要跟） |
| `normalizeProfile` 的默认值或取值域 | 40（README 配置表）、50（`cordis.patch.yml`） |
| 版本号 / 发版 | 全员 |
| 目录结构或加载链 | 全员 + 更新 `AGENTS.md` |

**回执与升级**

- 收到任务先回一句"收到，预计 X"，否则对方不知道你在不在。
- 5 分钟无回应 → 原发送方重发一次并抄送调度台；10 分钟仍无 → 调度台改派或串行化。
- 同一个失败连续两次 → 停手，报调度台，不许自己换路径绕过。

## 派活模板（调度台用）

一个任务 = 一个 owner + 一组可验收的路径。填不满六项就不要派：

1. 目标（可观察的最终状态）
2. 允许写的路径（精确到文件）
3. 明确不许碰的路径
4. 验收命令（能复制的）
5. 交付格式（改了哪些完整路径 / 测试输出原文 / 是否影响发布包）
6. 完成后通知谁

## 常见越界

- 界面身份为了让卡片显示新状态，直接去 `lib/index.mjs` 加字段 → 错，应向 10 提需求，由 10 改并广播。
- 测试身份为了让断言通过，把 `test/host.test.mjs` 的期望值改成实际值 → 错，应先确认是代码错还是期望错。
- 文档身份为了"图好看"，手工 P 图或直接引用 `preview/*.png` → 错，图只能由 `scripts/gen-gallery.cjs` + `scripts/screenshot.ps1` 生成。
- 发布身份为了赶版本，跳过测试直接 tag → 错，`publish.yml` 会失败，且不许改 workflow 去跳过测试。

## 怎么用

新会话开场说清"你是 20 号身份"或"你是调度台"，让它先读自己的文件和 `AGENTS.md`。
调度台派活时把模板填好，一次只派一个 owner 的一个任务；需要并行时最多 2 个写身份同时动工，且写路径不相交。
