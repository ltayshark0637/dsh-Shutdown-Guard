# Local development

> Chinese original: [DEVELOPING.md](DEVELOPING.md)

## 1. No build step

The source is the runtime code: `lib/index.mjs` is ESM and DSH imports it directly; `lib/client.js` is a self-contained bundle that the host compiles into its module graph at startup.

```
git clone https://github.com/ltayshark0637/dsh-Shutdown-Guard
cd dsh-Shutdown-Guard
node test/host.test.mjs
```

No `npm install` is needed: the repository has zero runtime dependencies, and the tests use only `node:test` and `node:assert`.
(Use `npm.cmd` for npm commands; the local PowerShell execution policy forbids `npm.ps1`.)

## 2. The two tests

```bash
node test/host.test.mjs      # host: mock ctx, never actually shuts down
node test/client.test.cjs    # client bundle smoke: real client.js against a fake React
```

After changing `lib/**` you **must run both**; after changing only docs or screenshot scripts you must still run `client.test.cjs` (the screenshots are generated from the real CSS in `client.js`, so broken styles fail there first).

Common assertion names and what they hold:

| Assertion | What it guards |
| --- | --- |
| `client-bundle-smoke` | `lib/client.js` can be `require`d and rendered |
| `i18n-coverage-ok` | the three-language key sets are level (see section 4) |
| `window-page-ok` / `window-tape-ok` | the floating-window page is still a complete document and the warning tape still follows the state |
| `window-radar-parity-ok` | the window page and the sidebar counters are same-source |
| `radar-dots-*-ok` | the dot cap, `+N`, aria, root filtering |
| `profile-*-ok` | the config system: no pre-generated empty slots, the last choice is remembered, cleanup rules |
| `theme-label-ok` / `builtin-palette-*-ok` | theme naming and the built-in Claude palette fallback |

## 3. Directory responsibilities

| Path | Responsibility |
| --- | --- |
| `lib/index.mjs` | Host side: gating checks, countdown, action execution, retry and circuit breaking, config persistence, HTTP routes, floating-window page |
| `lib/client.js` | Sidebar card: CSS + React in the same file |
| `lib/i18n.mjs` | Three-language message catalog and language resolution (`LANGS`, `resolveLang`) |
| `test/` | The two assertion scripts |
| `scripts/` | Screenshots, demo page, icons, release helpers (not runtime) |
| `docs/` | Maintainer docs (this file, CONFIG, ARCHITECTURE) and screenshot output |
| `data/` | Runtime data: `config.json`, `events.log`, `ui.json` — never committed |

## 4. The three language key sets must stay level

`MESSAGES` in `lib/i18n.mjs` uses `zh` as the baseline: every language must define **every key** of `zh`, and the key counts must be equal.
`i18n-coverage-ok` in `host.test.mjs` asserts three things:

1. `LANGS` is exactly `['zh', 'en', 'ru']`;
2. `catalogCoverage()`'s `missing` is an empty object (no language is missing a key);
3. every language's key count `=== coverage.base.length` (neither more nor fewer).

Client-side copy lives in the `MSG` table in `lib/client.js` and must be level across the three languages as well; change both sides together, or the card will show "one sentence in Chinese, one in English".

## 5. Mount chain: DSH must be restarted after a change

The repository root is the plugin directory, and DSH loads it through two chains:

1. `link:<absolute path to this directory>` in `harness\profiles\web\package.json`;
2. `harness\profiles\web\node_modules\dsh-shutdown-guard` → this repository root.

**The client bundle is compiled into the module graph only when DSH starts; refreshing the page does not load new code.** Changing `lib/client.js` and then looking at the old page is the same as not verifying at all. The same holds for the server side.

## 6. Screenshots and documentation images

All documentation images are generated by scripts from the real CSS in `lib/client.js`; **hand-edited images are not accepted**:

```bash
node scripts/gen-gallery.cjs --lang all --matrix   # 18 main images + the legacy page set
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/screenshot.ps1
node scripts/gen-thumbs.cjs                        # 18 settings-page thumbnails + base64
node scripts/gen-demo.cjs                          # docs/demo.html
node scripts/gen-banner.cjs                        # banner.html (then render banner.png with Edge)
node scripts/gen-gif.cjs                           # README uses the matrix images; the GIF is optional
```

Common `gen-gallery.cjs` flags:

| Flag | Effect |
| --- | --- |
| `--lang zh\|en\|ru\|all` | language; `all` generates all three |
| `--matrix` | the 18-image set `NN-armed-{a,b,c}-{zh,en,ru}-{light,dark}.png` |
| `--thumbs` | 18 settings-page thumbnail pages (handed to `gen-thumbs.cjs`) |
| `--only <substr>` | only generate pages whose name contains the string; useful when changing one image |
| `--state <view>` | override the state (`off` / `armed` / `hold` / `fire` / `fired` / `blocked`) |

`screenshot.ps1`'s `-Filter` takes a file-name wildcard and matches `.html` only. **Delete the intermediates `docs/screenshots/thumb-*.html` and `thumb-*.png` after use; do not commit them.**

The demo page takes its thumbnails directly from `docs/assets/variant-*.png` (GitHub Pages serves `docs/` as the site root, so `assets/` is a site-absolute path). When changing a thumbnail, update both `assets/` and `docs/assets/`.

## 7. Commit discipline

- **Do not `git add`**: this version has twice had the staging area swallow someone else's changes. Always commit by explicit path:

```bash
git commit -m "docs: …" -- README.md docs/CONFIG.md
git show --stat HEAD          # verify after every commit
```

- One file has one writer at a time; talk to the owner before touching someone else's file.
- Contract changes (state fields, event names, config keys, copy keys) must be broadcast to the parties that depend on them.
- Do not push and do not tag unless explicitly asked; a tag must equal the `version` in `package.json`.

## 8. Common pitfalls

| Pitfall | Symptom | What to do |
| --- | --- | --- |
| PowerShell writes UTF-8 with a BOM | `JSON.parse` throws on the BOM | `strip` the BOM before reading; write config with `fs.writeFileSync(..., 'utf8')` |
| PS 5.1 decodes a BOM-less script as ANSI | a backtick in a Chinese comment swallows the newline, reporting `Unexpected token '}'` | **`scripts/*.ps1` uses ASCII comments only** |
| `node -e` is expanded by PowerShell first | `${…}`, regexes and quotes cause a `SyntaxError` or empty output | write a temporary `.cjs` and run `node file.cjs` |
| `raw.githubusercontent.com` / `api.github.com` / `codeload` are unreachable locally | curl `(28)` timeout | read GitHub files via `https://cdn.jsdelivr.net/gh/<owner>/<repo>@main/<path>` |
| Rewriting a Chinese `.md` with `Set-Content -Encoding utf8` | the whole file turns into mojibake and line breaks are swallowed | write with the `edit` tool or node `fs`; for version-number-style edits do an **equal-length byte replacement** to preserve CRLF |
| The screenshot is not trimmed at the edges | the output shows Edge's default background colour | `screenshot.ps1` only renders `.html`; `Trim-Png` trims only on `alpha==0`, so the page must have no opaque background |

## 9. Release (summary)

Change visible behaviour → update both `CHANGELOG.md` and the `version` in `package.json` → commit → `git tag vX.Y.Z` → push the tag; `.github/workflows/publish.yml` runs the tests on `windows-latest` and then `npm publish`.
Authentication uses npm Trusted Publisher (OIDC); a token must never appear in the repository at any time. See `AGENTS.md` in the repository for details.
