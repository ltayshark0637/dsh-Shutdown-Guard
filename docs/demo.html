DeepSeek Harness Plugin

Shutdown Guard

任务完成后自动关机·侧边栏守夜卡片

为 DeepSeek Harness 的侧边栏添加「所有任务完成后自动关机」卡片，拥有更好且多样的视觉效果、判定逻辑与个性化定制。

五道判定闸 三种外观 个性化定制 AFK 自动接管 阻断态分级

01为什么需要它

跑长任务的人常有这个场景：晚上让 agent 把一批活干完，想让它干完就关机，人不在跟前。

但「任务结束」不等于「可以关机」——后台任务还在跑、会话报错了、agent 在等你回答问题、你在半路手动终止了……这些情况下关机全是事故。这个插件把这些情况逐个挡下来，只有真的可以关的时候才关。

02判定：什么时候才关

处于阻断态时直接不下发；其余五道闸门同时满足才下发 shutdown /s（C 形态那六格灯里，「只算成功」与「正在倒计时」是额外画出的两格，闸门还是五道）：

  1. 已武装 —— 你手动点的
  2. 没有倒计时在跑 —— 避免重复下发
  3. 所有 root 会话都空闲 —— 没有任何 agent 还在干活
  4. 没有运行中 / 停止中的后台任务 —— blockOnJobs，默认开
  5. 本批次没有会话报错 —— onlyOnSuccess，默认开

03三种外观

雷达里的圆点按数量增删、不重排：数量变化时，你正在看的那几个点不会跳位置。设置里切换，立即生效，无需重启。卡片和悬浮窗底部的警示带都跟着状态走：未武装或被阻断时是同色相的深浅两档，从武装开始、到真正执行关机为止是红黄斜纹，280ms 渐变过去、不闪；Claude Style 与 DeepSeek 蓝这两档不切红黄。下面的 04 一节把这两种状态并排放着，可以直接对比。

想自己动手试试？打开 试一试 —— 换外观、掷状态、看日志，都是本地随机的，不联网。

04六种运行状态

倒计时期间随时可取消，取消后仍保持武装——下一批任务干完照样会关。

05阻断态

遇到没法当普通失败处理的错误，插件不解除武装，卡片转色、把原因写出来：

  • halted · 灰蓝额度不足、凭证失效、上下文超限、能力不支持、磁盘写满。只有人能处理，点「解除并重试」。
  • waiting · 灰绿限流、5xx、网络中断、空响应、超时、图片卸载。按策略自动重试，到点注入「继续原计划」指令。

06AFK 自动接管

人不在跟前时，插件替你顶三件事：

  • 自动回答提问agent 问你问题时，回复「用户处于 AFK，先完成已交代的任务，汇总报告并落盘」。返回 selected: [] + 自定义文本，不会替你选中任何选项；关掉后提问照常抛给你。
  • 错误恢复会话报错时先要求 agent 排查并继续原计划；同一会话再失败改为「停止重试、写报告收尾」。
  • 中断保护你在半路手动终止任务，不会触发关机。

怎么玩
  1. 左边是它真正待的地方：技能中心下方、会话列表上方。点卡片右上角的窗口按钮，还能把它拉成独立窗口（默认简洁模式，只留卡片）。这页的卡片可以点，武装、取消、解除都在左边操作。
  2. 流程：随机场景 → 点卡片上的武装 → 开始检测 → 后台任务与会话逐个减少 → 全部结束后进入倒计时 → 下发。
  3. 检测途中会有小概率撞上阻断态：halted 要你点「解除并重试」，waiting 过几秒自己恢复。
  4. 倒计时期间你可以随时「取消关机」，模式仍保持武装；也可能撞上阻断。
  5. 真实插件的日志在 设置 → 状态，完整流水写在 data/events.log。这里倒计时用 12 秒，插件默认 60 秒。
